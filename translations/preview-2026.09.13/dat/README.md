# DAT translation working snapshot

These UTF-8 CSVs preserve the cumulative item, armor and weapon translation
work behind the experimental DAT candidate. They are work in progress, not a
100% quality or runtime claim. Columns are index, source and target; an empty
target retains source text. `{j}` separates text slots/lines in the toolkit's
CSV representation. Keep color and formatting controls intact.

Players should apply the hash-checked preview delta, not import these CSVs
with an arbitrary toolkit configuration. Correct pointer tables, untouched
numeric fields and strict archive/checksum validation are essential.
